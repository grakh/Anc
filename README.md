# Anctor

Утилита технолога для NC-программ AlphaCAM: файлы `.anc`, постпроцессор
**AEC GVM MTX** (Anderson). Один самодостаточный Tkinter-скрипт.

В репозитории — **Anctor V8.8** (191 КБ, `ver = 'Anctor V8.8'`).
Более ранняя версия V2.6 (апрель 2023) осталась в истории коммитов;
снимок промежуточной сборки — в `old/`.

## Что делает

**Проверка столкновений.** Разбирает `.anc` на PART'ы (`PREPART`) с элементами
вход / контур / выход, строит траекторию центра фрезы со смещением на радиус
(с учётом G41/G42) и ищет:
- врезание подвода/отвода в свою или чужую кромку;
- срезание контуром одного PART кромки другого.

Находки рисуются на канве с глубиной врезания и попадают в лог.

**Fix G-code** — коррекция ошибок стойки `Cornering: Tool too big!` и
`Corner peaks: A contact point could not be found…`:
- один R_min на группу программ (основные / мелкие углы / 3D — 3D не трогается);
- цепочки мелких дуг и почти плоских кадров спрямляются в `G1`;
- микро-кадры (< 10 мкм) удаляются с переносом конца;
- внутренние дуги меньше R_min заменяются касательной дугой R_min;
- прямой и обратный проходы одной геометрии держатся вместе (обратный
  строится как точное обращение исправленного прямого);
- переносится вход/выход с дуги на середину длинной прямой (опция);
- пересчитывается `CLN(DLAn)` под новое число кадров.

Оригиналы сохраняются в `_orig_fix` с журналом хэшей `fix_manifest.json`,
правка всегда идёт от оригинала.

**Вспомогательное.** Сверка угла/высоты ножа с XML заказа, комментарии
покупателя, правка параметров инструмента (`Angle`, `ABS`, `Height`, `add Comp`),
удаление измерений щупом (`Del Meas`), опрос папки NC после выгрузки из CAM.

## Запуск

```
pythonw anctor.pyw                 # окно
python  anctor.pyw <папка NC>      # разбор папки в консоли
```

Поле `Enter` — номер заказа; папки берутся по сети:
`\\storage\Zakaz\<NNN>000-<NNN>999\<номер>\<номер>-NC` и `…\JPG`,
XML заказа — `<заказ>\XML\specification_<заказ>.xml`.

## Требования

Python 3.11, `Pillow` (обязательно), `numpy` (для скруглений; без него эта
часть Fix тихо пропускается). Остальное — стандартная библиотека: `tkinter`,
`xml.etree`, `json`, `hashlib`.

Настройки — `anctor_settings.json` рядом со скриптом, создаётся при первом
сохранении из окна `☼`.

## Связь с CAMSYS

Логика Fix G-code дословно продублирована в
[CAMSYS](https://github.com/grakh/camsys) — `camsys/post/anctor_fix.py`, чтобы
программы выходили уже исправленными. Правки делать здесь и копировать туда
заново, иначе две программы разойдутся.
